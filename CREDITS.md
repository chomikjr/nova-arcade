# Third-party games

Nova Arcade hosts these open-source games. Each folder in `games/ports/` keeps the game's original license file. Changes made here: Google Analytics/AdSense and an external ad script were removed (Hextris, HexGL, A Dark Room, Hearts, Particle Clicker), CDN libraries were bundled locally (Particle Clicker, A Dark Room), and a GitHub ribbon was removed (Hearts). Source for every game, including GPL/MPL ones, is in this repository and upstream.
